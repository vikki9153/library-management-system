# Library Management System

A Java library management app with a responsive browser interface.

## Run

On Windows, run `run.bat`. It compiles the Java server and starts it locally. Then open <http://127.0.0.1:8080>.

The server stores books and students in `books.txt` and `students.txt` beside the app. These local data files are excluded from Git.

## Features

- Add and search books and students
- Issue and return books
- Track current loans
- Persist records between runs
- Responsive dashboard and library views
